# Shortcuter Frontend

Фронтенд приложение для сервиса сокращения URL **Shortcuter** на базе React + Vite.

## 🚀 Возможности

- **Сокращение URL** - создавайте короткие ссылки без регистрации
- **Личный кабинет** - управляйте своими ссылками
- **Пользовательские алиасы** - устанавливайте свои коды вместо автогенерируемых
- **Копирование в буфер** - быстрое копирование ссылок
- **Адаптивный дизайн** - работает на всех устройствах

## 📋 Требования

- Node.js 16.0 или выше
- npm 7.0 или выше

## 🔧 Установка

1. **Клонируйте или распакуйте проект:**
```bash
cd shortcuter-frontend
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Создайте файл `.env` (опционально):**
```bash
cp .env.example .env
```

Обычно API доступен на `http://localhost:8000`, но если у вас другой адрес, отредактируйте `.env`:
```
VITE_API_URL=http://localhost:8000
```

## 🏃 Запуск

### Режим разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

Vite автоматически проксирует API запросы на `http://localhost:8000`

### Продакшен сборка

```bash
npm run build
```

Собранные файлы будут в папке `dist/`. Можно развернуть их на любом статическом хосте.

### Предпросмотр собранного приложения

```bash
npm run preview
```

## 🔌 API Интеграция

Фронтенд взаимодействует с Shortcuter API на следующих эндпоинтах:

### Без авторизации
- `POST /api/links` - создать сокращённую ссылку
- `GET /{code}` - редирект на оригинальную ссылку

### Авторизация
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход
- `GET /api/my/links` - получить мои ссылки
- `DELETE /api/my/links/{id}` - удалить ссылку
- `PUT /api/my/links/{id}/alias` - установить алиас

## 📝 Использование

### Создание ссылки (без входа)
1. Введите URL в поле "Сократить URL"
2. Нажмите кнопку "Сократить"
3. Ссылка будет создана и скопирована в буфер обмена

### Регистрация и вход
1. Нажмите "Вход" в навигации
2. Введите email и пароль (минимум 8 символов)
3. Нажмите "Регистрация" для нового аккаунта или "Вход" для существующего

### Управление ссылками
1. После входа нажмите "Мои ссылки"
2. Здесь вы сможете:
   - Просмотреть все свои ссылки
   - Копировать ссылку в буфер обмена
   - Установить пользовательский алиас
   - Удалить ссылку

## 🐛 Решение проблем

### "Cannot find module" ошибки
```bash
rm -rf node_modules package-lock.json
npm install
```

### CORS ошибки при подключении к API
Убедитесь, что API запущен на адресе из `VITE_API_URL`. При разработке Vite автоматически проксирует запросы.

### Приложение не открывается
Проверьте, что порт 5173 не занят другим процессом. Вы можете изменить порт в `vite.config.js`.
